Profiling Quick Reference

perf — Sampling Profiler

Basic Recording

perf record -g ./program                    # Record with call graph (dwarf)
perf record -g --call-graph dwarf ./program # Explicit dwarf unwinding
perf record -F 99 -g ./program              # 99 Hz sampling (default ~1000-4000)
perf record -e cycles:u -g ./program        # User-space cycles only
perf record -e cache-misses -g ./program    # Profile cache misses specifically

Analysis

perf report                    # Interactive TUI
perf report --stdio            # Plain text
perf report --sort=symbol      # Flat profile by symbol
perf report --sort=dso,symbol  # Group by library then symbol
perf script                    # Raw samples (for flame graphs)
perf annotate                  # Annotated assembly (needs -g)

Hardware Counters (perf stat)

perf stat ./program                          # Default: cycles, instructions, cache, branches
perf stat -e cycles,instructions,cache-references,cache-misses,branch-instructions,branch-misses ./program
perf stat -e r10,r11,r12,r13 ./program         # Raw event codes (see 'perf list')
perf stat --repeat 10 ./program                # Run 10x for statistics

Common Hardware Events

EventDescription
cyclesCPU cycles (core clock)
instructionsInstructions retired
cache-referencesLLC (L3) cache accesses
cache-missesLLC cache misses
branch-instructionsBranch instructions retired
branch-missesMispredicted branches
L1-dcache-loadsL1 data cache loads
L1-dcache-load-missesL1 data cache load misses
stalled-cycles-frontendCycles stalled in frontend (fetch/decode)
stalled-cycles-backendCycles stalled in backend (execution)

Google Benchmark — Microbenchmarking

Basic Template

#include 

static void BM_Name(benchmark::State& state) {
  // Setup (outside timing loop)
  for (auto _ : state) {
    // Measured code here
    benchmark::DoNotOptimize(result);
    benchmark::ClobberMemory();  // If measuring memory effects
  }
}
BENCHMARK(BM_Name)->Arg(64)->Arg(1024)->Arg(16384);

BENCHMARK_MAIN();

Useful Methods

MethodPurpose
state.range(0)Get current argument value
state.SetBytesProcessed(n)Report throughput (bytes/sec)
state.SetItemsProcessed(n)Report throughput (items/sec)
benchmark::DoNotOptimize(x)Prevent dead-code elimination
benchmark::ClobberMemory()Force memory writes to be visible
state.PauseTiming() / ResumeTiming()Exclude setup/teardown from timing

Run Options

./bench --benchmark_repetitions=10           # Statistical significance
./bench --benchmark_min_time=1.0                 # Run each bench ≥1 sec
./bench --benchmark_format=csv                   # CSV output
./bench --benchmark_out=results.json --benchmark_out_format=json
./bench --benchmark_filter="BM_String.*"         # Regex filter

Flame Graphs

# Generate
perf script | flamegraph.pl > profile.svg

# Filtered (e.g., only your code)
perf script | grep -v "libc\|kernel\|ld-" | flamegraph.pl > profile.svg

# Differential (compare two profiles)
perf script | flamegraph.pl --diff=other.perf --negate=d > diff.svg

Compilation Flags for Profiling

FlagPurpose
-gDebug symbols (function names, line numbers)
-fno-omit-frame-pointerPreserve frame pointers for stack unwinding
-O2 or -O3Optimize (profile optimized code!)
-march=nativeUse host CPU features (for real-world perf)

CPU Frequency Control (for stable benchmarks)

# Check current governor
cpupower frequency-info

# Set performance mode (requires root)
sudo cpupower frequency-set -g performance

# Or via sysfs
echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

# Disable turbo boost for absolute stability
echo 1 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo

Useful Aliases

# Add to ~/.bashrc or ~/.zshrc
alias perf-record='perf record -g --call-graph dwarf'
alias perf-report='perf report --stdio'
alias perf-stat='perf stat -e cycles,instructions,cache-references,cache-misses,branch-instructions,branch-misses'
alias perf-flame='perf script | flamegraph.pl > profile.svg && xdg-open profile.svg'
