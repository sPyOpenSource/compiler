The iadd trace (one-liners)

  1. Pass 1: opcode 0x60 → new IMAdd(...) (CodeContainer.java:527).
  2. Pass 3: processStack pops two operands, pushes the tree (IMBinaryOperator.java:49).
  3. Optimize: IMAdd.constant_folding folds c+c, swaps to right-constant (IMAdd.java:45).
  4. Codegen: IMAdd.translate(Reg) → code.addl(reg, result) or code.addl(value, result) / code.incl(result) (IMAdd.java:107–183).
  5. Encode: BinaryCodeIA32.addl writes x86 bytes; ARM twin would be BinaryCodeDynamicARM.add → dpr/dpi(DP_ADD).
  6. Relocate: getOldBinaryCode() resolves symbol entries → BinaryCode → .jll/.jln.
